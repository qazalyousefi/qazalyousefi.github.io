# Ghazal Yousefi — Senior Product Designer Portfolio

Static portfolio site. Open `index.html`, or serve the folder with any static host (GitHub Pages works as-is).

- `index.html` — the whole site (pages are hash routes: `#Torob-casestudy`, `#Myket-casestudy`, `#Basalam-casestudy`, `#About-me`, `#Resume`)
- `Torob-casestudy.svg` — Torob case study for desktop; `tl/` holds the light image version used on phones and tablets
- `mk/`, `bs/`, `tb/`, `tv/`, `tvx/` — case study and mockup images
- `about/`, `logos/`, `resume.webp`, `ghazal.png` — About page, logos, resume image, profile photo
